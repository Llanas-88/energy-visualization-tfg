# GIS-Based Municipal Energy Simulator: Application to El Catllar

## Description

This project was developed as a Final Degree Project (Bachelor Thesis) for the Information Technologies Degree at the Universitat Oberta de Catalunya (UOC).

The objective of the project is to develop a GIS-based municipal energy simulator capable of spatially representing simulated energy consumption of buildings within the municipality of El Catllar through an interactive WebGIS application.

The system integrates cadastral data, a PostGIS spatial database, geographic services published through GeoServer, and a web map viewer developed with Leaflet.

## Main Features

* Interactive visualization of municipal buildings.
* Spatial representation of simulated energy consumption.
* Energy retrofit scenario simulation.
* Climate scenario simulation.
* Interactive dashboard with energy indicators.
* Building-level information through map popups.

## System Architecture

Cadastral Data → QGIS → PostgreSQL/PostGIS → GeoServer → Leaflet WebGIS → End User

## Technologies Used

* QGIS
* PostgreSQL
* PostGIS
* GeoServer
* Leaflet
* HTML
* CSS
* JavaScript
* Chart.js

## Data Sources

The project uses cadastral building data and official public datasets related to municipal energy consumption.

The energy values displayed by the simulator are simplified estimates generated from territorial data and reference consumption factors. They do not represent actual building-level energy consumption data.

## Project Purpose

The application is intended as a proof-of-concept and educational prototype demonstrating the integration of GIS technologies, spatial databases, web mapping services, and simplified energy modelling within a municipal-scale WebGIS environment.
