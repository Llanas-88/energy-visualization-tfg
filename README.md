# energy-visualization-tfg
Web app for municipal energy consumption visualization using GeoJSON and Python

Energy Consumption Visualization (TFG) - 
Web application developed as a final degree project to visualize municipal energy consumption data.

Features - 
  Visualization of energy consumption data
  Use of geospatial data (GeoJSON)
  Data processing using Python
  User-oriented interface for clarity and usability

Technologies - 
  Python
  GeoJSON
  QGIS
  HTML / CSS

Status - 
  Work in progress (Final Degree Project)

Goal - 
  To improve data understanding and support decision-making through clear visual representation.
